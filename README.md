# Real-Time Emotion Detection

A deep learning-based real-time facial emotion detection system using OpenCV and TensorFlow.

## Features
- Real-time face detection
- Emotion recognition
- Webcam integration
- CNN-based model

## Technologies Used
- Python
- OpenCV
- TensorFlow
- Keras
- NumPy

## Emotions Detected
- Angry
- Happy
- Sad
- Neutral
- Fearful
- Disgusted
- Surprised

## Run Project

```bash
pip install -r requirements.txt
python Detector_In_Action.py
```
