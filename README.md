# Real-Time Emotion Detection

A deep learning-based real-time facial emotion detection system that identifies human emotions using webcam input.

## Overview

This project uses Computer Vision and Deep Learning to detect facial expressions and classify emotions in real time.

## Features

- Real-time face detection
- Emotion recognition
- Webcam integration
- CNN-based model
- Live emotion display

## Emotions Detected

- Angry
- Disgusted
- Fearful
- Happy
- Neutral
- Sad
- Surprised

## Technologies Used

- Python
- OpenCV
- TensorFlow
- Keras
- NumPy

## Installation

Clone repository:

```bash
git clone https://github.com/yourusername/real-time-emotion-detection.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run project:

```bash
python Detector_In_Action.py
```
